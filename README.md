# Birthday site

Next.js (App Router) + TypeScript + three.js.

```
npm install
npm run dev
```

Open http://localhost:3000 (the mic only works on localhost or https).

- Fonts (Fraunces + Caveat) are bundled via @fontsource, so no internet is needed at build time
- Edit name, notes, envelopes, birth date and candles in `lib/config.ts`
- Put any photo at `public/guest.png` (shown as a polaroid)
